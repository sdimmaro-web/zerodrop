DOODROP — ПОДКЛЮЧЕНИЕ STEAM
===========================

ЧТО В АРХИВЕ
-------------
Это только изменённые и новые файлы. Скопируйте их в корень папки «казик»
с заменой старых файлов. Папки images, css и js должны остаться на своих местах.

ЧТО УЖЕ СДЕЛАНО
---------------
1. Настоящий вход через Steam OpenID 2.0.
2. Серверная проверка ответа Steam — SteamID не берётся из localStorage.
3. Загрузка ника, аватара, ссылки на профиль и статуса через Steam Web API.
4. Серверная сессия в защищённой HttpOnly cookie.
5. Кнопки «Войти через Steam» и «Выйти из аккаунта».
6. Исправлены ошибки profile.js: неопределённый balance, неверные селекторы,
   ручная подмена Steam-ника и аватара.

БЫСТРЫЙ ЗАПУСК НА WINDOWS
-------------------------
1. Установите Node.js 18 или новее.
2. Скопируйте содержимое архива в папку сайта.
3. Дважды нажмите START_STEAM_SERVER.bat.
4. При первом запуске появится файл .env.
5. Откройте .env и вставьте ключ после STEAM_API_KEY=.
6. Перезапустите START_STEAM_SERVER.bat.
7. Открывайте сайт только через http://localhost:3000,
   а не двойным нажатием на index.html.

ГДЕ ВЗЯТЬ STEAM WEB API KEY
---------------------------
Официальная страница:
https://steamcommunity.com/dev/apikey

Для локальной проверки в поле домена можно указать localhost.
Ключ никому не отправляйте и не вставляйте в JavaScript или HTML.
Он должен оставаться только в файле .env на сервере.

СОДЕРЖИМОЕ .env ДЛЯ ЛОКАЛЬНОГО ЗАПУСКА
---------------------------------------
HOST=127.0.0.1
PORT=3000
BASE_URL=http://localhost:3000
STEAM_API_KEY=ВАШ_КЛЮЧ
STEAM_API_BASE=https://api.steampowered.com

ЗАПУСК БЕЗ BAT
--------------
Откройте терминал в папке сайта и выполните:
node server.js

ПРОДАКШЕН / ХОСТИНГ
-------------------
Для настоящего домена измените:
HOST=0.0.0.0
BASE_URL=https://ваш-домен.ru

Steam callback будет:
https://ваш-домен.ru/auth/steam/return

Сайт должен работать через HTTPS. Рекомендуется поставить Node.js за Nginx
или панелью хостинга с reverse proxy.

ВАЖНО ДЛЯ БОЕВОГО САЙТА
-----------------------
Текущие сессии хранятся в памяти процесса и исчезают после перезапуска Node.js.
Для реального сайта следующий этап — база пользователей и Redis/БД для сессий.
Баланс, промокод, Trade URL и email пока хранятся в localStorage браузера — это
только демонстрация и не подходит для денег. Эти данные необходимо перенести в БД.

ЗАМЕЧАНИЕ ПО ИЗОБРАЖЕНИЯМ
-------------------------
В исходном архиве нет файлов avatar.png, knife.png, ak.png, m4.png, m4a1s.png,
awp.png, gloves.png и freddy.png, хотя HTML на них ссылается. Steam-аватар теперь

картинки нужно будет отдельно добавить или заменить их пути.
